INTERNSHIP PROJECT

Customer Data Platform

This Internship Project focuses on the implementation and management of a Customer Data Platform (CDP) using Treasure Data to centralize customer data from multiple sources into a single platform. The main objective is to improve customer data management and support data-driven decision-making for sales and customer engagement.

The project includes the main CDP processes such as ingestion, cleaning, transformation, unification, validation and dataset preparation for reporting and analytics. SQL and Microsoft Excel are used for data processing and quality checks while Power BI is used to create dashboards and reports. Power Automate is also used to automate selected workflows and improve efficiency. Throughout the project, collaboration with stakeholders ensures that the CDP meets business and reporting requirements, helping the organization manage customer data more effectively.

Key Features:

  • Managed and monitored a Customer Data Platform (CDP) powered by Treasure Data to centralize customer data from multiple organizational sources into a unified platform.
  • Involved in the end-to-end CDP workflow, including data ingestion, cleaning, transformation, unification, customer segmentation and activation.
  • Improved data management capabilities to support data-driven decision-making in sales and customer engagement teams.
  • Utilized SQL and Excel for data processing, validation and quality checks to ensure data accuracy throughout the development lifecycle.
  • Collaborated with stakeholders to ensure CDP data structures aligned with business and reporting requirements.
  • Supported downstream analytics by preparing CDP datasets for visualization and reporting use cases.

FINAL YEAR PROJECT

Sentiment Analysis and Reviews Classification for Sports Equipment Product Using LSTM

My Final Year Project focuses on the development of a web-based for Sentiment analysis and review classification system for sports equipment products using LSTM . The main objective of this project is to analyze customer reviews and classify them into different sentiment categories to provide better understanding of customer opinions and feedback.

The model classifies sentiment into three categories:

  • POSITIVE : Good Review.
  • NEUTRAL : Balanced Review.
  • NEGATIVE : Bad Review.

The system is developed using Python and HTML to provide an interactive web-based platform for users. Through this project, the system helps to analyze customer feedback more efficiently and gain valuable insights for improving product quality and services. The completed system deployed in demonstrating the application of deep learning and NLP techniques (LSTM) in real-world customer review analysis.

Key Features:

  • Developed a web-based system for sentiment analysis and review classification of sports equipment using HTML, CSS, PHP, SQL, Xampp, Bootstrap, JavaScript and JQuery.
  • Implemented deep learning (LSTM) combined with NLP techniques (TF-IDF and Word Embedding).
  • Collected and prepared own dataset from various e-commerce platforms and from Kaggle.
  • Designed the system to effectively analyze customer reviews and classify them based on sentiment (positive, negative, neutral).
  • Helped in understanding customer feedback better and can be useful for improving products and services.
  • Deployed the system using UKM server infrastructure, utilizing tools such as Sublime Text, FileZilla and Xampp for development and deployment.

SENTIMENT ANALYSIS PROJECT

Sentiment Analysis Model for Tweets Dataset (NLP Project)

This project involves developing a Sentiment Analysis Model that classifies tweets into positive, negative or neutral sentiments. By using the "movie_data.csv" dataset that contains tweet data collected from Twitter, the project aims to preprocess text data and evaluate multiple machine learning classifiers to determine their accuracy in sentiment prediction.

The preprocessing phase includes tasks such as text cleaning, tokenization and vectorization. The processed data is then used to train three different machine learning models which are Logistic Regression, Naive Bayes and Support Vector Machines (SVM). Each model is evaluated based on its performance in classifying sentiments, providing valuable insights into public opinions on various topics.

Key Features:

  • Collected the movie_data.csv from the twitter for specifically movie which is Oppenhaimer.
  • Included text pre-processing such as cleaning, tokenization and vectorization to prepare the data for analysis.
  • Implemented and compared of three machine learning classifiers: Logistic Regression, Naive Bayes, and SVM.
  • Evaluated of each classifier's performance to determine the most accurate model for sentiment prediction.
  • Analysis of public opinions by using tweet sentiment classification to gain actionable insights.

Tools Used:

Python
Excel
Google Colab
